lavinmq-bpf report

Zoomed in

Drag across the timeline to select a time range. One row per thread. Colored blocks are fiber runs of the minimum length or longer, gray bars behind them shorter runs summed per 10 ms, pale bars idle time. The ticks along the bottom of a row are CPU samples, one per 10 ms that the thread was on CPU: point at one for its stack, click it to select it. Red bands are GC stop-the-world pauses, when every thread is stopped. Memory is what the kernel counts resident: anonymous (the GC heap, malloc) below file backed (mapped segment files), the GC heap dashed; allocated is libgc's count per 100 ms. Click a run to select it and its thread; click a thread name to keep only that thread; Ctrl and the wheel zoom, Shift and the wheel pan.
